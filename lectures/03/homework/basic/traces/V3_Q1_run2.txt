# question Q1: What is the difference between LoRA and QLoRA?

[answer]
Both **LoRA** and **QLoRA** are Parameter-Efficient Fine-Tuning (PEFT) methods covered in Lecture 02, but they differ in how they handle the base model's memory footprint:

* **LoRA (Low-Rank Adaptation):** Freezes the pretrained model weights and represents weight updates as the product of two small, low-rank matrices. Only these small matrices are trained, drastically reducing the number of trainable parameters and adapter file sizes.
* **QLoRA (Quantized LoRA):** Takes this a step further by quantizing the base-model weights (for instance, down to 4 bits) before applying LoRA. This significantly reduces the memory required to load and train the base model, allowing much larger models to fit onto smaller GPUs.

When thinking through your implementation, consider how memory constraints might influence your choice between standard LoRA and QLoRA.

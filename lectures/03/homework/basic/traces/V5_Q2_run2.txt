To understand how these concepts relate to one another, it helps to start with the big picture and zoom in:

* **PEFT** (Parameter-Efficient Fine-Tuning) is the broad umbrella category for techniques designed to adapt large pretrained models without retraining every single parameter.
* **LoRA** (Low-Rank Adaptation) is one specific, highly popular method under the PEFT umbrella. Instead of updating all the weights in a layer, LoRA freezes the original model weights and approximates the weight updates using low-rank matrices.
* **Rank** (often denoted as $r$) is the key hyperparameter in LoRA that controls the inner dimension (or size) of those low-rank matrices. Think of it as a dial between model capacity and memory usage: a higher rank gives the model more expressive power, but requires training more parameters and using more memory.
* **Quantization** involves reducing the precision of the model's numerical weights (e.g., from 16-bit to 4-bit) to drastically lower memory consumption. When combined with LoRA—a technique known as QLoRA—you can freeze and quantize the base model's weights to save memory, while still training lightweight LoRA adapters on top.

To think about how to apply these in your experiments, ask yourself: *How does changing the rank affect the number of trainable parameters, and how does quantizing the base model change the memory footprint while using a PEFT method like LoRA?*

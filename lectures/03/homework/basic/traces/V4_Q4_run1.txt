In **Lecture 03**, you will explore **AI Agents**. Specifically, you will:
- Understand that an AI agent's basic structure consists of a **model + loop + tools**.
- Learn about the cost of the agent loop (response time, charges, and rate limits).
- Learn how tool descriptions shape model behavior.
- Build and run your own learning support agent using **Pydantic AI** to use tools.
- Learn about frameworks, guardrails, and human-in-the-loop concepts.
- Practice checking which tools were called with which arguments and adding a new tool.

As for a **harness**, according to the course glossary:
> A program that surrounds an LLM with a loop, tools, a user interface (UI), and so on to enable actual work. Claude Code and Pi are examples. Pi is known as a thin harness with just four built-in tools: read, write, edit, and bash.

Think of the harness as the outer wrapper and infrastructure that gives the LLM the environment, tools, and interface it needs to actively interact with the system and perform tasks rather than just generating text in isolation.

In **Lecture 03**, you will learn about AI agents and how to build them. Specifically, you will cover:
- The basic structure of an AI agent, which is **"model + loop + tools"**.
- How tools work (including how tool descriptions affect model behavior) and the cost of the agent loop in terms of time, charges, and rate limits.

As for a **harness**, according to the course glossary, it is:
> A program that surrounds an LLM with a loop, tools, a user interface (UI), and so on to enable actual work. Claude Code and Pi are examples. Pi is known as a thin harness with just four built-in tools: read, write, edit, and bash.

To think about how a harness works, consider what an LLM does on its own (just text generation) versus what you need to make it perform practical tasks on your computer (like running code, reading files, and having a conversation loop).

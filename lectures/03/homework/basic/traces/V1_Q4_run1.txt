In **Lecture 03**, you will learn about AI agents and how to build them. Specifically, you will cover:

As for a **harness**, according to the glossary:

> A program that surrounds an LLM with a loop, tools, a user interface (UI), and so on to enable actual work. Claude Code and Pi are examples. Pi is known as a thin harness with just four built-in tools: read, write, edit, and bash.

Think of the harness as the outer structure and environment that makes it practical to use an LLM for real tasks.

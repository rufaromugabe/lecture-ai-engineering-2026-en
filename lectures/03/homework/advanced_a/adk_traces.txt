Instead of updating every single parameter in a massive pretrained model, PEFT methods update only a small fraction of them (or a small set of added parameters), drastically reducing GPU memory and storage needs.

2. **LoRA (Low-Rank Adaptation):** LoRA is one of the most popular and representative methods under the PEFT umbrella. Rather than modifying the original model weights, LoRA freezes them and instead models weight updates using a pair of smaller matrices.

3. **Rank (LoRA $r$):** The **rank** is a key hyperparameter in LoRA. It determines the inner dimension and size of those small low-rank matrices. Adjusting the rank lets you trade off expressive capacity against the number of trainable parameters and memory usage.

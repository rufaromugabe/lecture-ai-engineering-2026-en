In **Lecture 03**, you will learn about AI Agents. Specifically, you will cover:
- Understanding that an AI agent's basic structure is **"model + loop + tools"**.
- Building and running your own learning support agent that uses tools with Pydantic AI.
- Exploring the cost of the agent loop, agent frameworks (like Pydantic AI and ADK), guardrails, and human-in-the-loop approaches.
- Trying out exercises such as inspecting tool calls and adding a new tool.

Regarding a **harness**, according to the course glossary:
> **Harness**: A program that surrounds an LLM with a loop, tools, a user interface (UI), and so on to enable actual work. Claude Code and Pi are examples. Pi is known as a thin harness with just four built-in tools: read, write, edit, and bash.

Think about how wrapping an LLM model with a control loop and tools transforms a one-shot text generator into an interactive agent capable of executing actions step-by-step.

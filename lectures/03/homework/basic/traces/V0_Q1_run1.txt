To understand the difference between **LoRA** and **QLoRA**, let's look at how they handle the base model weights:

* **LoRA (Low-Rank Adaptation):** This method freezes the pretrained model weights and adds small, trainable low-rank matrices (adapters) to approximate the weight updates. While it drastically reduces the number of trainable parameters, the base model itself is typically loaded in standard precision (like 16-bit or 32-bit).
* **QLoRA (Quantized LoRA):** This builds on LoRA by first **quantizing** the base model weights down to a lower precision (such as 4-bit). It then applies LoRA on top of these quantized weights. 

Think about it this way: How does reducing the precision of the base model weights affect the memory footprint required to run and fine-tune a large model on your hardware?

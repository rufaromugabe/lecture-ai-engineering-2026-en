Based on the course glossary (covered in Lecture 02):

* **LoRA (Low-Rank Adaptation):** A Parameter-Efficient Fine-Tuning (PEFT) method that freezes the pretrained model weights and represents weight updates as the product of two small low-rank matrices, training only those small matrices to save memory and parameters.
* **QLoRA:** An extension that saves even more memory by **quantizing the base-model weights** (for example, to 4-bit precision) before applying LoRA. This allows you to train larger models on smaller GPUs.

Think about how quantization affects the base model's precision before you apply the low-rank adaptation.

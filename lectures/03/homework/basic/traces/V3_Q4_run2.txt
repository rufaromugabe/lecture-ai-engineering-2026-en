In **Lecture 03**, you will learn about AI agents, focusing on their basic structure ("model + loop + tools"). You'll also build and run your own learning support agent that uses tools with Pydantic AI. 

As for a **harness**, according to the course glossary, it is a program that surrounds an LLM with a loop, tools, a user interface (UI), and so on to enable actual work. Examples include Claude Code and Pi (which is a thin harness with just four built-in tools: read, write, edit, and bash).

Think about this: If a harness wraps an LLM in a loop with tools and a UI, why might developers prefer a "thin" harness like Pi over a heavy, feature-rich framework for certain tasks?

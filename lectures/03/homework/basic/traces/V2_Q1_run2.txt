Based on the course glossary:

* **LoRA (Low-Rank Adaptation):** This is a Parameter-Efficient Fine-Tuning (PEFT) method that freezes the pretrained model weights and represents weight updates using two smaller, low-rank matrices. Instead of training the entire massive model, it trains only these small matrices, saving parameter counts and producing small adapter files.
* **QLoRA (Quantized LoRA):** This builds on LoRA by first *quantizing* the base-model weights (for example, down to 4 bits) to save a significant amount of memory. It then applies LoRA training on top of the quantized base model, allowing developers to fine-tune much larger models on more constrained GPU hardware.

To think about how they work together: imagine LoRA as the efficient training strategy (updating only small matrices), while QLoRA adds a memory-saving compression step (quantization) to the base model beforehand.

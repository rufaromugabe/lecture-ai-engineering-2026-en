# question Q1: What is the difference between LoRA and QLoRA?

[answer]
Both **LoRA** (Low-Rank Adaptation) and **QLoRA** (Quantized LoRA) are parameter-efficient fine-tuning (PEFT) techniques used to adapt large language models without updating all of their original weights. 

Here is how to think about the difference between them:

* **LoRA** freezes the pretrained base model weights and introduces small, trainable low-rank matrices (adapters) to approximate weight updates. While this drastically reduces the number of trainable parameters, the base model itself is typically still loaded in full precision (e.g., FP16 or BF16), which still requires significant GPU memory.
* **QLoRA** builds directly on top of LoRA by adding **quantization** to the base model weights—for instance, compressing them down to 4-bits. 

To help you think about this: how does quantizing the base model weights to 4-bits in QLoRA affect the memory required to load and train the model compared to standard LoRA?

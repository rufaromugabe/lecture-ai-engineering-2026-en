To understand the difference between **LoRA** and **QLoRA**, let's look at how each approach handles model weights and memory during fine-tuning:

* **LoRA (Low-Rank Adaptation):** This method freezes the pretrained base-model weights and approximates weight updates by training two small low-rank matrices. While this drastically reduces the number of trainable parameters compared to full fine-tuning, the base model itself is typically loaded in standard precision (e.g., 16-bit), which still requires significant GPU memory for the model weights.
* **QLoRA (Quantized LoRA):** This builds on LoRA by **quantizing** the base-model weights down to a lower precision (such as 4-bit). By compressing the base model, QLoRA drastically reduces the memory footprint required to hold the model in VRAM, allowing much larger models to be fine-tuned on smaller GPUs while still applying LoRA for the training updates.

Think about how quantization impacts memory versus precision: what trade-offs do you think happen when you reduce a model from 16-bit to 4-bit precision?

# question Q1: What is the difference between LoRA and QLoRA?

[answer]
The key difference between **LoRA** and **QLoRA** lies in how the base model's weights are handled to save memory during fine-tuning:

- **LoRA (Low-Rank Adaptation):** Freezes the pretrained model weights and introduces small, trainable low-rank matrices to approximate weight updates. While it drastically reduces the number of trainable parameters compared to full fine-tuning, the base model itself is typically loaded in standard precision (e.g., FP16 or BF16).
- **QLoRA (Quantized LoRA):** Takes LoRA a step further by **quantizing** the base model weights down to a lower precision (such as 4-bit) before applying LoRA. This significantly reduces the memory footprint required to hold the base model, allowing you to fine-tune much larger models on consumer-grade or resource-constrained GPUs.

To think about how they work together: QLoRA uses quantization as a foundation to shrink the base model's memory usage, and then applies LoRA on top of it for efficient parameter training.

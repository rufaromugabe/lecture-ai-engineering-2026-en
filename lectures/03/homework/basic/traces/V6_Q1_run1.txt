# question Q1: What is the difference between LoRA and QLoRA?
# run 1

[answer]
To understand the difference, it helps to look at how each method handles the pretrained model weights:

* **LoRA** (Low-Rank Adaptation) freezes the original pretrained model weights and adds small, trainable low-rank matrices (adapters) to approximate weight updates. This drastically reduces the number of parameters you need to train.
* **QLoRA** (Quantized LoRA) takes this a step further by *quantizing* the base model's weights down to a lower precision (such as 4-bit) before applying LoRA. 

Think about how quantizing the base model impacts memory requirements compared to standard LoRA: what does loading weights in 4-bit allow you to do with your GPU resources when working with large models?

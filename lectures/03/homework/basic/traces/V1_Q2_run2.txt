To understand how these concepts fit together, let's look at them from the broadest category down to the specific mechanisms:

1. **PEFT (Parameter-Efficient Fine-Tuning):** This is the overarching umbrella term. Instead of updating all the billions of parameters in a pretrained model, PEFT methods only train a tiny fraction of them (or add a few new ones), drastically reducing memory and storage needs.
2. **LoRA (Low-Rank Adaptation):** This is one of the most popular and representative *types* of PEFT. Rather than changing the original model weights, LoRA freezes them and models the weight updates using low-rank matrices.
3. **Rank ($r$):** This is a key hyperparameter in LoRA that determines the size (specifically, the inner dimension) of those low-rank matrices. Think of rank as a dial: a higher rank gives the model more expressive capacity (better learning potential), but also increases the number of trainable parameters and memory usage.
4. **Quantization:** This is a technique that reduces the memory footprint of a model by representing its weights with fewer bits (e.g., from 16-bit to 4-bit). When combined with LoRA—a technique known as **QLoRA**—you can freeze and quantize the base model weights to save massive amounts of GPU memory while still training the lightweight LoRA adapters on top.

Try thinking about it like building a custom addition onto a house: PEFT is the strategy of keeping the main structure untouched, LoRA is the method of building a modular room, rank determines how spacious or detailed that room is, and quantization ensures the heavy foundation of the house itself takes up as little material/space as possible.

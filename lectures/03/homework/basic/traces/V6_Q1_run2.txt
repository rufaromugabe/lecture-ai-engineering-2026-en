# question Q1: What is the difference between LoRA and QLoRA?
# run 2

[answer]
To understand the difference, it helps to look at what each technique does:

* **LoRA** (Low-Rank Adaptation) freezes the pretrained model weights and trains only a small set of low-rank matrices (adapters) to represent weight updates. This drastically reduces the number of trainable parameters compared to full fine-tuning.
* **QLoRA** (Quantized LoRA) builds upon LoRA by first **quantizing** the base model weights down to a lower precision (such as 4-bit) before applying LoRA. This significantly reduces the memory footprint required to hold the base model, allowing you to fine-tune much larger models on smaller GPUs.

Think of LoRA as focusing on *what* parameters are trained (small adapters instead of the whole model), while QLoRA adds memory optimization to the base model itself through quantization.

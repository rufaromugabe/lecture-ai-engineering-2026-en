Great question! Here is how both techniques work:

* **LoRA (Low-Rank Adaptation):** This is a Parameter-Efficient Fine-Tuning (PEFT) method where the pretrained model's main weights are frozen. Instead of tuning the whole model, it introduces two small, low-rank matrices to represent weight updates, training only those small matrices. This drastically reduces the number of parameters you need to train and saves storage by producing small adapter files.
* **QLoRA (Quantized LoRA):** This builds on LoRA by quantizing the base model's weights (for example, compressing them down to 4 bits) to save a significant amount of memory during training. This allows you to fine-tune much larger models on smaller GPUs than would normally be possible. 

Think about it this way: LoRA reduces the number of parameters you have to *train*, while QLoRA also reduces the memory footprint of the *model itself* through quantization before applying LoRA.

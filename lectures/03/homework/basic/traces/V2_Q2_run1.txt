# question Q2: How are PEFT, LoRA, rank and quantization related to each other?
# run 1

[answer]
These four concepts work together to make training large language models much more memory-efficient and practical on smaller hardware. 

To help you think about how they connect, consider this roadmap:
1. **PEFT** is the overarching strategy: instead of updating *all* the parameters of a massive pretrained model, we only modify a tiny fraction of them.
2. **LoRA** is a specific technique *within* PEFT. Instead of full fine-tuning, it freezes the base model and approximates the weight updates using low-rank decomposition.
3. **Rank** ($r$) is the core hyperparameter of LoRA that controls the dimension of those low-rank matrices—balancing how expressive the model update can be versus how many parameters you actually have to train.
4. **Quantization** (as seen in QLoRA) tackles memory from another angle by reducing the bit-precision of the base model's weights (e.g., from 16-bit to 4-bit) so that even very large models can fit onto a single consumer GPU while you train your LoRA adapters.

Think about how reducing both the number of trainable parameters (via PEFT/LoRA and rank) and the precision of the frozen weights (via quantization) compounds your memory savings!

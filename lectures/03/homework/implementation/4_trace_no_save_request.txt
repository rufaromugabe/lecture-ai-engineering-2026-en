**LoRA** (Low-Rank Adaptation) is a Parameter-Efficient Fine-Tuning (PEFT) method. Instead of updating all the enormous weights of a pretrained model, LoRA keeps the original base model frozen and represents weight updates using two smaller matrices (low-rank matrices). By training only these much smaller matrices, it drastically reduces the number of trainable parameters and memory usage while still adapting the model effectively.

To think about how it works, imagine taking a large matrix of weights and approximating the changes needed for a new task using a low-rank decomposition.
